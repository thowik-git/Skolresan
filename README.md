# Skolresan 🚌

En enkel reseplanerare för bussresor mellan hemmet och skolan, som en fristående webbapp (PWA).

- Tidtabeller och realtid från Trafiklab **ResRobot v2.1** – alla bolag i Sverige
- Visar avgångstid, ankomsttid och restid i minuter, med filter per bolag
- Lägg till på hemskärmen för att använda som app

API-nyckeln ligger **inte** i koden. Den läggs in under ⚙️ i appen och sparas bara lokalt i webbläsaren.
